# Sabine River Metal Works Website Scope

## Overview

Static HTML website for Sabine River Metal Works, a Beaumont, TX local service business focused on pole barns, red iron buildings, metal roofing, custom awnings and metal structures. SEO is a primary requirement, so each service has its own crawlable HTML page with unique titles, descriptions, headings, calls to action and local service-area language.
